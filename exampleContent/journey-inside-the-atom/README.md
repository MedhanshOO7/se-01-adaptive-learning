# Journey Inside the Atom — research package

**Working scope:** NCERT *Exploration*, Grade 9 Science (2026), chapter 8, for CBSE Class IX 2026–27. The existing repository's Class 9 atom chapter makes this the best working interpretation of “atoms chapter”; Class XII Physics also has a different chapter called “Atoms”. Chapter 9, *Atomic Foundations of Matter*, is related but is not included here.

- [Sources and scope](sources.md): edition, page references, curriculum and evidence limitations.
- [Chapter content](chapter-content.md): an original, section-by-section account of the chapter, examples and terminology.
- [Concepts and depth map](depth-map.md): granular concepts, dependencies, depth progression, misconceptions and evidence.
- [Assessment and activities](assessment-activities.md): original diagnostic questions with answers, activity ideas and a source exercise inventory.

These files are paraphrased research notes, not a transcription of the textbook. Use the linked official PDF for exact wording, illustrations and all exercises. Teacher review is needed before publication. Research checked 31 October 2026.
